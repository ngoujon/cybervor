Télécharger

Gratuit, sans compte : un identifiant invité est créé automatiquement au premier lancement. Votre progression est sauvegardée dans le cloud.

⬇ Cybervor 0.2.0 pour Windows (.zip, 68 Mo)
  1. Décompressez le fichier zip où vous voulez (sur le bureau, par exemple).
  2. Lancez Cybervor.exe. Le jeu n'est pas signé : si Windows SmartScreen s'affiche, cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
  3. Jouez ! Le jeu se connecte tout seul aux serveurs. Il reste jouable hors ligne.
  4. Mises à jour automatiques à partir de la 0.2.0 : le jeu se met à jour tout seul. Vous aviez la 0.1.0 ? Téléchargez une dernière fois et décompressez par-dessus : votre sauvegarde est conservée.
